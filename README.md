# 🧹 C 盘清理大师

> 一个用 Python + pywebview 写的 Windows C 盘清理工具，界面现代、功能全面、安全可靠。

## ✨ 功能特性

### 🗑️ 清理
- **一键清理**：临时文件 / 浏览器缓存 / 系统垃圾 / 回收站 / NVIDIA 显卡缓存
- **微信 / QQ 专清**：按图片 / 视频 / 语音 / 文件分类，只清缓存，聊天记录绝对不动
- **文件粉碎机**：覆写后永久删除，敏感文件无法恢复

### 🔍 查找
- **大文件扫描**：找出 C 盘占用空间最大的文件，带安全标签
- **磁盘地图**：ECharts 树状图，一眼看出谁在吃你的硬盘，支持下钻
- **重复文件**：MD5 比对找出内容完全相同的文件
- **空文件夹**：一键清理没用的空目录
- **卸载残留**：找出已卸载软件留下的空壳文件夹

### 🛠️ 工具
- **系统信息面板**：CPU / 内存 / C 盘 / 电池实时监控
- **清理历史**：本月清理量统计，成就满满
- **定时关机**：倒计时自动关机
- **系统托盘**：关闭到右下角，右键快速清理

### 🎨 体验
- 深色 / 浅色主题一键切换
- 清理动画（垃圾桶飞入 + 卡片吸入）
- Windows 系统提示音
- 窗口大小自动记忆
- 启动动画、平滑过渡

### 🛡️ 安全
- 系统关键文件硬编码黑名单，永远不会被删
- 所有删除默认移入回收站，可恢复
- 聊天软件只清缓存，`.db` 数据库永不触碰
- 进程白名单，避免误删正在使用的文件

## 🚀 使用方法

1. 前往 [Releases](https://github.com/123aa-bit/c-drive-cleaner/releases) 页面
2. 下载最新的 `C盘清理大师.exe`
3. 双击运行，无需安装

> ⚠️ **首次运行可能被 Windows Defender 或杀毒软件拦截**，这是因为 exe 未做代码签名。点击"仍要运行"即可。
